# Дорожная карта Waydroid Stacks

Цель проекта — дать Linux то, что Windows-пользователи получили от BlueStacks,
и пойти дальше: сделать Android-игры частью Linux-гейминга без «костылей».
Ниже — направления, отсортированные по важности для уникальности решения.

## v0.2 — «Ближе к BlueStacks»

- [ ] **Мультиинстанс**: несколько независимых Android-контейнеров
      одновременно (свои копии data-раздела, реестр инстансов, переключение
      и параллельный запуск игр — как в BlueStacks Multi-Instance).
- [ ] **Профили производительности на игру**: разрешение/DPI виртуального
      экрана, лимит FPS, CPU governor, приоритет процесса.
- [ ] **Геймпады**: проброс через `uhid`/evdev в Android, плюс маппинг
      стиков/кнопок геймпада на тач-виджеты (совместно с кеймаппером).
- [ ] **Запись геймплея и скриншоты**: аппаратная запись (GStreamer/VA-API)
      в MP4, горячая клавиша, галерея клипов.
- [ ] **Экспорт/импорт раскладок**: файлы `.wsk` (JSON) — поделиться профилем
      с другом, импорт в один клик.
- [ ] Исправления UX по итогам реальной игры: калибровка координат при
      масштабировании окна, курсор, повторное подключение стрима.

## v0.3 — «Сверхнизкая задержка» (уникальное ядро)

- [ ] **Прямой захват экрана Android без H.264**: вместо scrcpy-видео —
      zero-copy доступ к поверхности через Waydroid-сокеты/DMA-BUF
      (wayland screencopy → GTK4 GdkDmabufTexture). Это уберёт кодирование,
      декодирование и лишний буфер — задержка ввода/вывода станет как у
      нативного окна. Ни один существующий инструмент этого не делает.
- [ ] **Инъекция через uinput без adb**: виртуальное устройство ввода в
      контейнере вместо control-сокета — не нужен scrcpy-server, задержка
      меньше, работает даже при отвале adb.
- [ ] **Инерционный обзор** (мышь как тачпад): захват указателя, сглаживание,
      чувствительность на виджет — поведение «как в шутерах», а не «жёсткий» тач.
- [ ] Собственный Wayland-композитор сессии (в духе cage) для фуллскрина без
      внешнего окна и корректного захвата ввода.

## v0.4 — «Экосистема»

- [ ] **Магазин раскладок**: публичный индекс профилей в репозитории
      (games/brgame.json и т.д.), поиск по названию игры, установка в один клик,
      рейтинг и версии раскладок.
- [ ] **Интеграция с магазинами приложений**: RuStore и установка APK/XAPK
      из встроенного файлового менеджера (drag&drop на окно).
- [ ] **Автообнаружение установленных игр** и предложение готовой раскладки.
- [ ] **Резервные копии игровых данных**: снапшоты data-разделов инстансов,
      перенос между машинами.
- [ ] Локализация интерфейса (en/ru) и тёмная/светлая темы.

## v1.0 — «Стабильность и дистрибуция»

- [ ] Заморозка формата профилей (`version: 1`) + миграции старых версий.
- [ ] Тесты: юнит-тесты ядра (протокол, маппер, каталог), CI на GitHub Actions.
- [ ] Пакеты: AUR (`waydroid-stacks`), Flatpak, опционально `.deb`/`.rpm`.
- [ ] Режим Steam Deck / Bazzite: gamescope-compatible запуск, управление
      с геймпада, интеграция «Добавить в Steam».
- [ ] Плагины раскладок сообщества как отдельные файлы без обновления ядра.

## Идеи «на потом» (вау-фичи)

- Автоматическое построение раскладки: анализ экрана игры (CV/ML) находит
  джойстик и кнопки и предлагает готовые виджеты.
- Синхронизация буфера обмена и файлов между хостом и Android.
- Мультиоконность: несколько игр рядом в одном окне (мозаика).
- «Прокси-инстанс» для старых ARM-игр: автоподбор libndk/libhoudini на инстанс.
- Привязка к KDE Activities / виртуальным рабочим столам: «игровой режим».
