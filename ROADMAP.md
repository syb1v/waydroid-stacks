# Дорожная карта Waydroid Stacks

Цель проекта — дать Linux то, что Windows-пользователи получили от BlueStacks,
и пойти дальше: сделать Android-игры частью Linux-гейминга без «костылей».

Статусы: `[ ]` — план, `[~]` — в работе, `[x]` — готово, `[!]` — блокер.

## v0.2 — «Ближе к BlueStacks» (готово в 0.2.0)

- [x] **Экспорт/импорт раскладок** `.wsk`: поделиться профилем, импорт в один клик.
- [x] **Скриншоты в игре**: горячая клавиша `F8`, сохранение в XDG-папку изображений.
- [x] **Запись геймплея**: горячая клавиша `F9`, запись H.264 в MP4 без
      перекодирования (GStreamer `tee` + `mp4mux`), индикатор записи.
- [x] **Профили производительности на игру**: разрешение и FPS стрима в профиле
      раскладки, применяются при запуске этой игры.
- [x] **Геймпады**: чтение evdev-устройств, кнопки/крестовина/стики
      превращаются в клавиши `pad:*` и маппятся на тач-виджеты. Проброс
      физического геймпада в Android — отдельно (uhid), исследуем.
- [x] **UX-фиксы по итогам реальной игры**: разморозка контейнера, повторное
      подключение стрима одной кнопкой, защита reverse-туннелей.

## v0.3 — «Сверхнизкая задержка» (уникальное ядро)

- [ ] **Прямой захват экрана Android без H.264**: zero-copy доступ к
      поверхности через DMA-BUF/screencopy → GTK4 `GdkDmabufTexture`.
      Убирает кодирование/декодирование и лишний буфер.
- [x] **Нативная инъекция ввода через evdev-FIFO** (лучше, чем uinput):
      Android в Waydroid читает ввод из FIFO `/dev/input/wl_touch_events`,
      `wl_keyboard_events`, `wl_pointer_events` (патч EventHub). Пишем
      `struct input_event` напрямую → событие попадает в EventHub минуя
      scrcpy-server и Java-инжектор; полноценный мультитач (10 слотов),
      задержка ниже. Автоматический откат на control-сокет scrcpy.
- [x] **Инерционный обзор** (мышь как тачпад): захват указателя через
      XWayland (`XWarpPointer`: курсор возвращается в центр, движение
      бесконечное), сглаживание дельт (EMA) и инерция после остановки,
      чувствительность на виджет.
- [x] **Тихая IME для текстовых полей**: собственная клавиатура без
      экранного интерфейса перехватывает ввод в полях Android — текст и
      спецклавиши идут через `InputConnection` (Unicode, кириллица,
      Backspace/Enter/стрелки), экранная клавиатура не перекрывает игру.
- [x] **Пакеты и релизы**: `.deb`, `.rpm`, автономный AppImage, PKGBUILD
      для AUR, установка одной командой (`scripts/install.sh`, `curl | bash`),
      автосборка и публикация релизов через GitHub Actions.
- [ ] Собственный Wayland-композитор сессии (в духе cage) для фуллскрина
      без внешнего окна и корректного захвата ввода.
