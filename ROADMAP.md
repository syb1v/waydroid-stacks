# Дорожная карта Waydroid Stacks

Цель проекта — дать Linux то, что Windows-пользователи получили от BlueStacks,
и пойти дальше: сделать Android-игры частью Linux-гейминга без «костылей».

Статусы: `[ ]` — план, `[~]` — в работе, `[x]` — готово, `[!]` — блокер.

## v0.2 — «Ближе к BlueStacks» (в работе)

- [ ] **Экспорт/импорт раскладок** `.wsk`: поделиться профилем, импорт в один клик.
- [ ] **Скриншоты в игре**: горячая клавиша `F8`, сохранение в XDG-папку изображений.
- [ ] **Запись геймплея**: горячая клавиша `F9`, запись H.264 в MP4 без
      перекодирования (GStreamer `valve` + `mp4mux`), индикатор записи.
- [ ] **Профили производительности на игру**: разрешение и FPS стрима в профиле
      раскладки, применяются при запуске этой игры.
- [ ] **Геймпады**: чтение evdev-устройств, кнопки/крестовина/стики
      превращаются в клавиши `pad:*` и маппятся на тач-виджеты. Проброс
      физического геймпада в Android — отдельно (uhid), исследуем.
- [ ] **UX-фиксы по итогам реальной игры**: калибровка координат при
      масштабировании окна, повторное подключение стрима одной кнопкой.

## v0.3 — «Сверхнизкая задержка» (уникальное ядро)

- [ ] **Прямой захват экрана Android без H.264**: zero-copy доступ к
      поверхности через DMA-BUF/screencopy → GTK4 `GdkDmabufTexture`.
      Убирает кодирование/декодирование и лишний буфер.
- [ ] **Инъекция через uinput без adb**: виртуальное устройство ввода в
      контейнере вместо control-сокета scrcpy — не нужен scrcpy-server.
- [ ] **Инерционный обзор** (мышь как тачпад): захват указателя, сглаживание,
      чувствительность на виджет.
- [ ] Собственный Wayland-композитор сессии (в духе cage) для фуллскрина
      без внешнего окна и корректного захвата ввода.

## v0.4 — «Экосистема» и мультиинстанс

- [!] **Мультиинстанс** — требует форка Waydroid: в upstream жёстко зашиты имя
      контейнера `waydroid` и путь `/var/lib/waydroid` (issue #566), готовый
      форк — `multidroid`. Задача: исследовать интеграцию клонирования
      data-раздела и запуск второго контейнера, не ломая штатный Waydroid.
- [ ] **Магазин раскладок**: публичный индекс профилей в репозитории,
      поиск по названию игры, установка в один клик.
- [ ] **Интеграция с магазинами приложений**: RuStore, установка APK/XAPK
      drag&drop на окно приложения.
- [ ] **Резервные копии игровых данных**: снапшоты data-разделов, перенос.
- [ ] Локализация интерфейса (en/ru), тёмная/светлая темы.

## Идеи «на потом» (вау-фичи)

- Автопостроение раскладки: CV/ML-анализ экрана игры предлагает джойстик и кнопки.
- Синхронизация буфера обмена и файлов между хостом и Android.
- Мультиоконность: несколько игр рядом в одном окне (мозаика).
- Автоподбор libndk/libhoudini на инстанс.
- Привязка к KDE Activities: «игровой режим».
